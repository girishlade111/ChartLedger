# ChartLedger Research Archive

This directory stores permitted public research, open-source audits, environment tool discovery, and feature comparison matrices created prior to and during the independent development of **ChartLedger**.

## Contents
- `evidence-register.json`: Structured registry classifying every researched claim as `VERIFIED_PUBLIC`, `VERIFIED_OSS`, `VERIFIED_ENV`, or `UNVERIFIED`.
- `competitor/bullgpt/feature-inventory.md`: Public-only capability inventory of BullGPT (`bullgpt.io`) with strict ethical/legal boundaries.
- `open-source/aionui/audit.md`: License, architecture, security, and reuse audit of `iOfficeAI/AionUi` (Apache-2.0).
- `tools/rea/discovery.md`: Container environment discovery for `morluto/rea` (Reverse Engineer Anything) and local toolchain.
- `reports/feature-comparison.md`: Final feature comparison matrix comparing verified public capabilities against ChartLedger's implementation and test status.

## Compliance Statement
- No private APIs, authentication boundaries, proprietary prompts, or scraping circumvention were used.
- No BullGPT trademarks, logos, screenshots, or copy are reproduced in the application.
